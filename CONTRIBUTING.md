# Contributing

Thanks for helping improve this project.

## Before starting

Open an issue to discuss significant changes. Keep pull requests focused and describe the user-visible behavior they change. Avoid committing API keys, generated exports, or personal data.

## Development

Run a local HTTP server with `python3 -m http.server 8000`, then open http://localhost:8000. Node.js 20 or newer is required for checks.

Before opening a pull request, run:

```sh
npm run check
npm test
```

## Pull requests

Include a concise summary, testing performed, screenshots for UI changes, and any known limitations. Respect third-party asset licenses and attribution requirements. Keep the procedural-generator and external Poly Pizza integration behavior clearly distinguished in documentation.
