# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately using GitHub's **Report a vulnerability** feature under the repository Security tab, if enabled. If unavailable, contact the maintainer privately rather than posting exploit details in a public issue.

Include reproduction steps, affected versions, and potential impact. Do not include credentials or private user information.

## Scope

This browser-based prototype can accept a Poly Pizza API key in session memory. Do not commit API keys or publish keys in issues. Public browser clients cannot keep user-provided keys secret from their own users; production shared integrations should use a server-side proxy.

There is no guaranteed response or remediation timeline.
